## Scénario

J'interviens en tant que Consultant Data Analyst chez Lapage, une librairie physique avec plusieurs points de vente qui a récemment décidé de se lancer dans la vente en ligne.

L'entreprise a besoin d'aide pour comprendre ses données, j'ai donc présenté au service Marketing une analyse des KPI et une analyse ciblée de sa clientèle.

## Objectifs et compétences
- **Objectif 1** : Analyser un jeu de données avec séries temporelles pour mesurer un phénomène statistique
- **Objectif 2** : Réaliser des tests statistiques sur des données afin de tester et valider des hypothèses

**Compétences développées** : 

- Statistiques descriptives, analyse des indicateurs et corrélations
- Réalisation de graphiques
- Synthèse de l'information

## Technologies utilisées
- **Python** : Pandas pour manipuler les tables, Matplotlib et seaborn pour les visualisations, Scipy pour les outils statistiques

## Structure du projet
Le projet est organisé comme suit :
- **Donnees_initiales** : Contient les données brutes.
- **Livrables** : Contient le notebook Python
- **presentation.pdf**, **presentation.odp** : PowerPoint présentant ma démarche et mes conseils
- **besoins_client.pdf** : PDF contenant l'expression des besoins du client
